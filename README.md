# Касса класса

Сервис для казначеев школьных классов: сборы со ссылкой на банковский сбор, отметки родителей
«Я оплатил», подтверждение оплат, расходы с фото чеков, баланс кассы и раздел с информацией класса.
Ставится на телефон как приложение (PWA).

## Адреса
- `/` — главная страница сервиса
- `/account` — регистрация и вход казначея, список своих классов
- `/c/<адрес-класса>` — страница класса для родителей (без входа)
- `/c/<адрес-класса>/admin` — кабинет казначея
- `/owner` — кабинет владельца сервиса (все классы, продление подписок)

## Запуск
Нужен Node.js 22.13+ (встроенный SQLite), внешних зависимостей нет.

    DATA_DIR=/data OWNER_EMAIL=you@example.ru npm start

Или Docker: `docker build -t kassa . && docker run -p 3000:3000 -v kassa-data:/data -e OWNER_EMAIL=... kassa`.

| Переменная | Что это | По умолчанию |
|---|---|---|
| `PORT` | порт | 3000 |
| `DATA_DIR` | папка базы и фото (нужен постоянный диск) | `./data` |
| `OWNER_EMAIL` | почта владельца сервиса (через запятую) | — |
| `PRICE_RUB` | цена подписки за класс в год | 399 |
| `TRIAL_DAYS` | бесплатный период | 30 |

Персональные данные: хранятся только фамилия и имя ребёнка; хостинг должен быть в РФ (152-ФЗ).
